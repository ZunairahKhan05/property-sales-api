# London Property Sales API

A RESTful back-end API, built with Python Flask and MongoDB, for searching and analysing residential property sales in Greater London. Developed for COM661 Full Stack Strategies and Development, Coursework 1.

## Dataset

- **Source:** HM Land Registry Price Paid Data, 2026 yearly file (1 January to 28 August 2026), filtered to Greater London.
- **Size:** 39,969 sales across 33 London boroughs, grouped into **39,537 property documents** (one document per address).
- **Attribution:** Contains HM Land Registry data (c) Crown copyright and database right 2021. This data is licensed under the Open Government Licence v3.0.
- **Generated data:** the Land Registry file has no bedrooms, bathrooms, floor area or features. A `details` sub-document with these fields was generated by `scripts/import_data.py` (fixed random seed, sensible ranges per property type) and every generated record is marked `"synthetic": true`. Properties added through the API store real values with `"synthetic": false`.

## Data model (database `propertyDB`)

**`properties`**, one document per address:

| Field | Type | Notes |
| --- | --- | --- |
| `address` | sub-document | paon, saon, street, locality, town, district, county, postcode |
| `property_type` | text | detached, semi-detached, terraced, flat, other |
| `tenure` | text | freehold or leasehold |
| `sales_history` | array of sub-documents | sale_id, transaction_id, price, date_of_transfer, new_build |
| `details` | sub-document | bedrooms, bathrooms, floor_area_sqm, features[], synthetic |
| `reviews` | array of sub-documents | review_id, user, rating (1 to 5), comment, date |
| `viewings` | array | reserved for future use |

**`users`**: username, email, bcrypt-hashed password, role (`user` or `admin`).

**`blacklist`**: login tokens cancelled by logout, with their expiry time. A TTL index on `expires_at` makes MongoDB delete each entry automatically once the token has expired.

## Roles

| Role | How | Can do |
| --- | --- | --- |
| Guest | No token | Browse, search and view properties, sales and reviews |
| User | Register, then log in | Everything a guest can, plus write reviews (edit or delete only their own) and use analytics |
| Admin | Created with `scripts/create_user.py` | Everything, including adding, editing and deleting properties and sales, and removing any review |

Roles are checked on the same URLs with the decorators `@jwt_required` and `@admin_required`, plus owner checks for reviews.

## Endpoints

All URLs start with `http://127.0.0.1:5001/api/v1.0`. POST and PUT requests use form data (`x-www-form-urlencoded`). Protected requests send the login token in the `x-access-token` header.

| Method | Endpoint | Access | Purpose |
| --- | --- | --- | --- |
| POST | `/auth/register` | Guest | Create a user account |
| GET | `/auth/login` | Guest (Basic Auth) | Log in and receive a JWT valid for 8 minutes |
| GET | `/auth/logout` | User, admin | Cancel the current token |
| GET | `/auth/me` | User, admin | Show the logged-in username and role |
| GET | `/properties` | Everyone | List with pagination, filters and sorting |
| GET | `/properties/<id>` | Everyone | One property |
| POST | `/properties` | Admin | Add a property |
| PUT | `/properties/<id>` | Admin | Edit a property |
| DELETE | `/properties/<id>` | Admin | Delete a property |
| GET | `/properties/<id>/sales` | Everyone | Sales history of a property |
| POST | `/properties/<id>/sales` | Admin | Add a sale |
| PUT | `/properties/<id>/sales/<sale_id>` | Admin | Edit a sale |
| DELETE | `/properties/<id>/sales/<sale_id>` | Admin | Delete a sale |
| GET | `/properties/<id>/reviews` | Everyone | Reviews of a property |
| GET | `/properties/<id>/reviews/<review_id>` | Everyone | One review |
| POST | `/properties/<id>/reviews` | User, admin | Add a review (one per user per property) |
| PUT | `/properties/<id>/reviews/<review_id>` | Author or admin | Edit a review |
| DELETE | `/properties/<id>/reviews/<review_id>` | Author or admin | Delete a review |
| GET | `/analytics/average-price` | User, admin | Average price and number of sales by district and type |
| GET | `/analytics/price-trend` | User, admin | Average price and number of sales by month |

**Query parameters for `GET /properties`:** `pn` (page, default 1), `ps` (page size 1 to 100, default 10), `district`, `postcode` (starts with), `property_type`, `tenure`, `bedrooms`, `min_price`, `max_price` (most recent sale), `sort` (`price_asc`, `price_desc`, `newest`, `oldest`).

**Analytics filters:** `district` and `property_type`.

**Status codes used:** 200 OK, 201 Created, 400 Bad Request (invalid input), 401 Unauthorized (missing, expired, invalid or cancelled token, or wrong login), 403 Forbidden (wrong role or not the author), 404 Not Found, 409 Conflict (duplicate account, address or review).

## Database features used

- Multi-value search combining district, postcode prefix (`$regex`), type, tenure, bedrooms and a price range.
- Aggregation pipelines: `$match`, `$addFields` with `$sortArray` and `$last` (most recent sale), `$unset`, `$count`, `$sort`, `$skip`, `$limit` for the property list; `$unwind`, `$group` (`$avg`, `$sum`), `$project` (`$round`, `$toInt`, `$substrCP`) for analytics.
- Sub-document CRUD with `$push`, the positional operator (`sales_history.$`, `reviews.$`) and `$pull`.
- A TTL (time-to-live) index on `blacklist.expires_at` so expired tokens are removed automatically.

## Setup and running (Windows, PowerShell)

1. Install Python 3.13, MongoDB Server (running on `mongodb://localhost:27017`) and MongoDB Database Tools.
2. Create and activate a virtual environment, then install the packages:
   ```
   python -m venv venv
   .\venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```
3. Download the 2026 Price Paid Data CSV from GOV.UK, save it as `data/pp-2026.csv`, then build the database:
   ```
   python scripts/filter_london.py
   python scripts/import_data.py
   ```
   Expected output: `Sales read: 39969` and `Properties inserted: 39537`.
4. Create an admin account: `python scripts/create_user.py`
5. Start the API: `python app.py`
